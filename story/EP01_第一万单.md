# 骡马阿甘 EP01 ·《第一万单》

> 目标时长：**约 170 秒**（2 分 50 秒）
> 镜头数：**30**
> 预算：**820 秒视频配额**（30 镜 × 7 秒 ≈ 210 秒素材，留 600 秒重做余量）

---

## 一、这次要解决什么问题

上一版观众需要脑补，因为：

| 问题 | 具体 |
|---|---|
| **身份没建立** | 观众不知道他是外卖员。没有接单、没有手机、没有送到的完整过程 |
| **"一直在送"没形成** | 只拍了 1–2 单，重复感不够，观众感受不到"他天天在送别人的重要日子" |
| **数字没分量** | "第五单"观众无感。应该是**第 9996 单 → 第 10000 单**，差四单，这个才有紧张感和仪式感 |
| **因果缺失** | 他为什么一个人？他家人呢？为什么最后是陌生人给了他一块蛋糕？ |
| **细节空** | 没有数单号、看时间、擦汗、等红灯——没有"劳动者"的体感 |

### 解决原则（四条）

1. **每个信息都要有画面**，不靠旁白解释。
2. **手机屏幕当"信息道具"**：单号、时间、地址，直接给观众看。
3. **三单重复结构**：让观众自己形成预期——"他又要送别人的生日了"。
4. **对比不用说服**：别人的笑脸拍三次，他的脸拍三次，观众自己会难受。

## 二、故事

**今天是阿甘的生日。今天他也要送出人生第一万单。**

**这两件事，只有他自己知道。**

## 四、为什么这次讲得清楚

| 上一版 | 这一版 |
|---|---|
| 没有身份交代 | **S01 手机屏幕直接给"9996 单"** |
| "第五单"没意义 | **9996 → 9997 → 9999 → 10000**，四镜递进，有仪式感 |
| 只送了一单 | **三单各拍"取—送—别人反应"，重复三次** |
| 别人的幸福只出现一次 | **出现三次（一家人 / 求婚 / 父子）**，观众自己会对比 |
| 他为什么孤独没交代 | **S07 等红灯、S08 擦汗、S19 站楼道听笑声**——用身体细节说 |
| 结尾的蛋糕来得突然 | **S11/S15/S18 观众已经看过三次"别人家的门开"**，最后一次是给他的，对比成立 |
