## 二、声音是这一集的节奏本身

**喜剧的"静 → 响"就是节奏。所以小声段必须真的静。**

### 实测数据

| 段落 | 音量 |
|---|---|
| 小声配送段（18–40s） | **均值 −49 dB** |
| 门铃第一声（41–43s） | **峰值 −25 dB** |
| **落差** | **24 dB** |

**观众听到的：他连呼吸都放轻了 → 然后"叮咚"炸开。**

### 鹦鹉的声音是这集最难的技术点

它必须像"学舌"，不能像人念台词。**如果鹦鹉听起来和人一样，整个笑点就塌了。**

三层做法：

1. **音源**：云夏（正太童声）+ 音高 **+62~66Hz** + 语速 +26~34% → 尖、快
2. **音色**：带通 320–3600Hz（模拟鸟的窄发声带）+ 压缩 + 短回声
3. **门铃**：**程序合成**两个电子音（叮=1318Hz / 咚=1046Hz，指数衰减），
   在鹦鹉说"叮咚"的位置**叠加真实门铃音**

> **全片门铃动机用同一条 `bell.mp3`**（剧本要求音色一致，不能每次换一个声音）。

## 三、三个坑（都换了思路，不是堆 prompt）

### 3.1 ⛔ "蹄手停在门铃前一厘米"—— 模型直接画成手指按上去

**第一版 prompt**：`a hoof slowly approaches, stops one centimetre before touching it`

**结果**：画面里一根**人类手指**按在门铃上。**全片核心证据镜直接反了。**

**原因**：一厘米是极精细的空间控制，图像模型做不到；而且它天然倾向"手靠近按钮 = 手按按钮"。

**修法：用构图代替距离**

```
门铃在画面左上
蹄子在画面右下，举在半空
中间是一大片空白
```

**这样"没碰到"是构图保证的，不依赖模型理解"一厘米"。**

实测结果：首帧蹄子悬空，尾帧蹄子退出画面，**门铃全程没亮** ✓

### 3.2 ⛔ 双人镜头里冒出人类

`14_door_open` 第一版画面里多了一个**穿绿衣服的人类**。全动物世界破裂。

**原因**：prompt 里没写"这是全动物世界"，模型默认补了一个人类邻居。

**修法**：明写 `an all-animal anthropomorphic world — absolutely NO humans`
+ 明写阿甘站在 `cool dim CORRIDOR`、兔子站在 `warm lit ROOM`（冷暖也要分开）。

（代价：兔子忘了戴耳机。但观众通过 10 镜已经知道它在开会，不影响理解。）

### 3.3 ⛔ "门缝 + 一双眼睛"两次都做不出来

两次生成都是**门全开、没有眼睛**。

**决定不死磕。改用声音：**

> 18 镜用现有走廊图，**加三声程序合成的门轴吱呀**（0.55s，噪声+带通+滑频），
> 让观众"听到"整层楼开门。

**一扇门开一条缝在画面里很难生成，但"三声门轴响"在音频里一秒钟就能做出来。**
笑点（"一份外卖叫醒整层楼"）保住了，成本几乎为零。
