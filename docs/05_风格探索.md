# 风格探索 —— 赛博朋克与三个替代方向

> 日期：2026-10-22
> 触发：用户「加入一些赛博朋克风，或者其他的你觉得合适的风格」

---

## 一、先说我判断的冲突

用户要赛博朋克。**它和本片的契合点是天然的：**

- 赛博朋克的核心命题就是「高科技、低生活」——**底层劳动者**
- 外卖骑手是赛博朋克世界最典型的职业（雨夜穿行、算法压榨、随时在线）

**但它和立项书的两条硬设定直接冲突：**

| 立项书写的 | 赛博朋克给的 |
|---|---|
| 美式卡通复古风 | 冷调霓虹 / 反乌托邦 |
| **暖褐色调** | 蓝紫冷色 |
| **治愈、解压** | 压抑、窒息 |
| **明确拒绝负能量** | 负能量是它的底色 |

**所以本批出四个方向，让实际效果说话。**

---

## 二、四个方向（同一角色骨架，只换风格）

### C1 纯赛博朋克

霓虹雨夜、全息招牌、发光的领带与外卖袋、青紫冷光。
**视觉冲击最强，但压抑感最重**——和"治愈"完全相反。
⚠️ 毛色被霓虹吃掉了（变成灰驴）。

### ⭐ C2 暖赛博朋克（折中方案）

**保留暖褐底色 + 复古卡通网点**，只加两色霓虹（黄 + 青）做点缀：
帽檐一圈青光、领带发光边、袋子青边、耳朵上一圈光环、旁边飘着全息价签。

**结果：有科技感，但完全不压抑，仍然治愈。**
配色纪律：暖褐做底 → 只有两个霓虹强调色 → 不打架。

### ⭐ C3 Solarpunk 太阳朋克

**赛博朋克的反面**：高科技但明亮、绿色、乐观、社区互助。
太阳能板、风力发电机、爬满绿植的白色建筑、帽子上有太阳能贴片。

**治愈感最强，和立项书的"拒绝负能量"最配。**
但代价：**乌托邦太干净，失去了"底层"的重量**——阿甘的"扛"就没有着力点了。

### ⭐ C4 复古未来主义（1970s）

"1978 年的人想象的明天"：橘子 + 奶油 + 橄榄绿、圆顶塔楼、泡泡车、
**搪瓷质感的硬壳配送箱**、圆润塑料机械。

**和立项书的"美式卡通复古"最同源**（同一血脉往前推一代）。
**搪瓷配送箱是目前最好的道具设计**——比布袋有记忆点，而且质感独特。

## 三、我的判断

| 方案 | 赛博感 | 治愈感 | 与立项书契合 | 记忆点 |
|---|---|---|---|---|
| C1 纯赛博 | ★★★★★ | ★ | ★ | ★★★ |
| **C2 暖赛博** | ★★★★ | ★★★★ | ★★★★ | ★★★★ |
| C3 Solarpunk | ★★ | ★★★★★ | ★★★★★ | ★★★ |
| **C4 复古未来** | ★★★ | ★★★★ | ★★★★★ | ★★★★★ |

**我推荐 C2 或 C4：**

- **要"科技感 + 不压抑"** → C2
- **要"复古 + 独特道具"** → C4（那个搪瓷箱真的很好）

**C1 不建议做正片基调**，但**可以做"特殊集"**（比如《送单到 2077》）——一次性反差点会让系列更有层次。
**C3 不建议**：太干净，阿甘"扛着生活"的重量没了。

## 四、这批图佐证了一个重要问题

**四张图的角色都不一样**：毛色（棕/灰/粉棕/灰）、体型（瘦/胖/胖/中）、
手型（蹄/手套/蹄/蹄）、耳朵角度……

**同一个 prompt 骨架，出来四个不同的角色。这就是"漂移"。**

**所以定下风格后要立刻做的事：**

```
定风格 → 立刻矢量化锁死（docs/04_矢量精修工作流.md）
       → 之后所有改动都在矢量上做，永不漂移
```

**这也正是"AI 出形 + 矢量精修"分工的意义所在。**
