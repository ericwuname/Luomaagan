## 一、故事

**今天是阿甘的生日，没有人记得。但他送的每一单，都是别人的生日。**

他是骡子——马和驴的杂交，天生不能生育。他爸是赛马，他妈是母驴。
「那夜，我爸犯了错，然后有了我」，**他本身就是一个"意外"。**

**一个"不该出生"的人，认真给自己过生日。** 这就是全片的情感引擎。

他在干的事，是把别人的重要日子一单接一单送到别人手上——蛋糕、鲜花、礼物。
**他一直在送"别人的生日"。**

结尾不煽情：他坐在台阶上，一小块蛋糕上插一根火柴。
吹灭，抬头看城市。旁白只说一句「谁又不是个美丽的意外呢」。
**不哭，不喊，不解释。**

## 二、⛔ 配音的"怪"，是这一版最关键的修正

### 病因：我给一个少年配了 45 岁的大叔音

查证 Edge TTS 官方声音定位：

| 声音 | 官方定位 | 年龄 |
|---|---|---|
| 云健 YunjianNeural | **低沉浑厚大叔，硬汉/武将** | **38–55 岁** |
| 云希 YunxiNeural | **清爽阳光少年，少年男主** | **18–27 岁** |
| 云夏 YunxiaNeural | 正太少年童声 | 7–15 岁 |
| 云扬 YunyangNeural | 央视浑厚播音 | 35–55 岁 |

**上一版阿甘用的是云健——38 到 55 岁的硬汉。这就是违和的根源。**
不是发音问题，是**年龄和气质完全错位**。

### 修正：阿甘 → 云希

**并且同一个人不同情绪，靠语速+音高区分，而不是换声音**（换声音会变成另一个角色）：

| 情绪 | 语速 | 音高 | 台词 |
|---|---|---|---|
| 小小得意 | +8% | +3Hz | 今天是个大日子 |
| 自嘲但坚定 | +2% | +2Hz | 没人记得，那就自己记住 |
| 兴奋 | +22% | +6Hz | 第一万单，出发！ |
| 手忙脚乱 | +25% | +8Hz | 马上马上 |
| 讨好陪笑 | +12% | +4Hz | 叔，就一分钟 |
| **失落** | **−18%** | **−4Hz** | 第五单 |
| **极轻，几乎自语** | **−20%** | **−3Hz** | 许个愿吧 |

**同一个云希，从 +22% 到 −20% 就是从欢快到落寞的整条曲线。**

### 配角各司其职

| 角色 | 声音 | 为什么 |
|---|---|---|
| 店员 | 云希 +30% | 同一个声音加速就变急躁，比换人自然 |
| 保安 | 云健 −8% | 大叔音在这里才合适 |
| 小女孩 | 云夏 +30Hz | ⚠️ zh-CN 只有 8 个声音，**没有孩童女声**。云夏是唯二标 Cartoon 的之一（正太童声 7–15 岁），抬音高做出孩童感 |
| 妈妈 | 晓伊 | 温柔治愈（Cartoon 类） |
| 旁白 | 云夏 −12% | 念最后一句要稳，不能飘 |

**台词总量 41.8s / 14 条。成片 103s，其余全是留白和环境声。**

## 五、运镜

**15 段全部用"运镜写第一句 + 全大写 + 禁止方向 + 描述画面元素怎么变"。**

但有一个新发现：

> **运镜 prompt 必须服从首帧的实际构图，不能按想象中的构图写。**

S04 我原本写"侧向跟拍"，但首帧实际是**正面朝镜头**。
改成"摄影机以同样速度后退"才对——画面里巷墙从两侧向后掠过。

**实测 S01 推镜有效：首帧人物小，尾帧推近变大。**

## 六、踩到的三个坑

### 6.1 `Select-Object -First N` 会杀掉正在运行的脚本

视频脚本用 `| Select-Object -First 12` 截断输出，
**PowerShell 在收到 12 个对象后关闭管道，把上游进程终止了。**

结果：视频只跑了 6 段就停，我以为是脚本自己结束了。

**修：长时间运行的脚本不要接 `Select-Object -First`。**

### 6.2 网络中断会留下"看似存在但已损坏"的文件

S09 报 `IncompleteRead(2315745 bytes read, 211545 more expected)`——
下载中断，但文件已写了 2.3MB。
**如果只判断"文件存在且 >80KB"，下次会跳过它。**

修：补拍脚本每次重试前**先删残缺文件**，下载后用 `ffmpeg -f null -` 解码校验。

### 6.3 配音起点算错会切掉尾巴

V07 有 4.40s，我原来放在 S06 的 3.30s 处 → 结束 7.70s，但 S06 只有 7.0s。
**最后 0.7 秒会被切掉。**

修：**配音起点 + 配音时长 ≤ 段时长**，逐条核过。S06 延长到 7.6s，S15 延长到 11s。
