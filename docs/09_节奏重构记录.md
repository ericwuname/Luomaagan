# EP01 v3 —— 节奏重构（呼吸感）

> 用户反馈：「剪辑没有呼吸感，感觉就像是着急赶场一样」
> 产出：`release/骡马阿甘_EP01_v3.mp4`（38.08s）
> 时长从 28.6s → 38.1s，**因为不再把台词硬压进短镜头**

---

## 一、诊断：六条"赶场"的病因

查证的专业规则逐条对上：

| 问题 | 具体 | 专业规则 |
|---|---|---|
| **① 时长均匀** | 3.4/3.4/5/3.4/5/3.4/5，匀速推进 | 要有长短交替，"全片都快"会让观众适应并麻木 |
| **② 违反"远长近短"** | S6 是特写却给 3.4s | **远景 2-3s 起，特写 1-2s 足够**，多给就是浪费耐心 |
| **③ 每镜都在完成任务** | 戴帽→骑车→压弯→指牌→深呼吸→吃面包，做完就切 | **温情需要"多余"的时间**：转身后多停两秒、说完多留一个沉默 |
| **④ 零留白** | 7 个镜头全是"主角在做事"，没有空镜、没有反应镜头 | 留白三法：空镜 / 反应镜头 / 疑问句过渡 |
| **⑤ 把 5 秒台词压进 2.4 秒镜头** | ⭐ **"赶"最直接的来源** | 镜头应服从台词，不是反过来 |
| **⑥ 结尾戛然而止** | 字幕结束就黑 | 结尾要慢下来，留回味 |

---

## 二、核心改动：镜头时长服从台词的天然长度

**上一版的思路是"先定镜头时长，再把台词塞进去"，塞不下就 atempo 加速到 1.5-1.6 倍。**

那是灾难：**1.6 倍速的中文听起来是慌的。**

**这一版反过来：先量台词多长，镜头就给多长（前后加气口）。**

| 配音 | 实际时长 | 给的镜头时间 |
|---|---|---|
| 那夜，我爸犯了错… | 4.25s | 5.0s（前 0.45 气口） |
| 他是匹英俊的赛马… | 4.83s | 5.3s（这句本来就长，镜头跟着长） |
| 橙蜜蜜让一让… | 5.28s | 5.7s |
| 这小骡子，天天玩特技！ | 2.71s | 3.0s |
| 叔，这是八十八楼… | 4.58s | 5.0s |
| 大家说我是个错误。 | 2.68s | 3.0s |
| 但在骡马城…意外呢？ | 4.47s | 8.2s（★长镜留白） |
| 明天见，骡马城。 | 2.85s | ↑ 同一镜后段 |

**代价：总长 28.6s → 38.1s。但立项书本来就写「1-3 分钟/集」。**

## 三、三处留白（呼吸的实体）

| # | 位置 | 时长 | 内容 | 音频 |
|---|---|---|---|---|
| **①** | S4 桥段之后 | **0.9s** | **刹车特写**（车轮擦火花、犀牛货车巨轮压过） | **-43dB** |
| **②** | S6 电梯之后 | **0.8s** | **静帧**（他吸气前的一刻，肩膀在抖） | **-48dB** |
| **③** | 全片结尾 | **3.0s** | **城市空镜** | 渐弱到 **-54dB** |

**人声 -20dB，留白 -43 至 -54dB，落差 23–34dB。**
这就是"停下来喘口气"的听感——不是静音，是**房间底噪还在，但人声撤了**。

## 四、节奏曲线

```
时长  5.0  5.3  5.7  3.0  0.9  5.0  3.0  0.8  8.2  3.0
       慢   中   快   快   停   中   慢   停   长   收
       ↑              ↑         ↑         ↑    ↑    ↑
     开场扫环境     最快     急停      静帧  天台  空镜
                                      （最静）    （淡出）
```

**中间三次"停"（0.9 / 0.8 / 3.0），这就是呼吸。**

## 五、旁白重新分配（画面与情绪咬合）

上一版把 13.78 秒旁白一整段塞进前 4 个镜头，导致 S3/S4 的对白全废。

**这一版拆成 4 段，并且把最重的一句搬到了它该在的地方：**

| 句子 | 从 | 搬到 | 为什么 |
|---|---|---|---|
| 「大家说我是个错误。」 | 开头 | **S6 电梯**（他一个人对着镜子理领带、肩膀在抖） | 画面和情绪咬合，不再是旁白信息 |
| 「谁又不是个美丽的意外呢？」 | 开头 | **S7 天台**（画面就是这座城） | 说这句话时看着城，才有分量 |
| 「橙蜜蜜让一让…」 | 被废弃 | **S3 骑车** | 欢快段终于有了自己的对白 |
| 「这小骡子，天天玩特技！」 | 被废弃 | **S4 桥** | 旁观者视角，增加真实感 |

## 六、转场纪律

| 位置 | 处理 |
|---|---|
| 开头 | **淡入 0.5s**（实测亮度 25→83→117） |
| 动作段之间 | **硬切**（铁律：动作段不能溶解，会磨掉冲击力） |
| 结尾 | **淡出 1.2s**（实测亮度 135→111→55→26） |

## 七、踩到的两个坑

### 7.1 `total` 用了设计值，导致淡出完全没出现

设计 39.90s，实际拼接只有 38.08s。
淡出起点按 39.9-1.2=38.7s 算 —— **落在片尾之后，淡出等于没做**。

修：拼接完先 `dur_of(vfix)` 拿实际时长，再用它算淡出。

> **教训：任何"总时长"相关的计算，必须用实测值，不能用设计值。**

### 7.2 环境底曲线用硬编码时间点，段落一变就错位

上一版 `bed_pts` 写死了 (0, 5, 10, 15…) 秒。
S7 少了 1.37s 后，整条曲线全部错位。

修：**改成按段落驱动** —— 每个段落一个情绪音量，从 `starts` 数组推时间点。
