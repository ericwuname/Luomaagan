# 阿甘角色设计 · 形状语言诊断与方案

> 日期：2026-10-22
> 触发：用户「主角没有那种让人一眼就能记住的特征」
> 累计：5 批 / 23 张

---

## 一、诊断：为什么 v1~v3 的 11 张图全部失败

**根因一句话：全身都是圆形语言。**

| v1~v3 的构成 | 形状语言含义 |
|---|---|
| 圆头 | 温暖、天真 |
| 圆肚子 | 柔软、可爱 |
| 圆眼 | 友好、无害 |
| 圆蹄 | 憨厚 |

**「圆形 = 温暖友好天真」= 可爱。**
**而「可爱」正是它记不住的原因——所有萌系角色都可爱，可爱不是差异。**

## 二、查证到的四条硬规律

### 2.1 迪士尼「10 英里剪影」测试

> 角色必须在白墙前作为**一团纯黑的形状**就能被读懂。迪士尼 1930 年代就把这条制度化了。

**米老鼠**：三个圆形组成正面（两个小圆 + 一个大圆）
**海绵宝宝**：**方形躯体** + 滑稽五官
**哆啦A梦**：大量圆形 + 一个红色鼻子的强色点
**爆笑虫子**：红虫圆润迟缓 vs 黄虫细长敏捷，**体型差固定 1:1.8**

**共同点：形状本身就是记忆点，不依赖细节。**

### 2.2 形状语言 = 情绪的速记符号

| 形状 | 情绪含义 | 代表 |
|---|---|---|
| **圆形** | 温暖、友好、安全、天真 | 米奇、阿宝、BB-8 |
| **方形** | 扎实、可靠、**固执**、迟缓 | 超能先生、卡尔 |
| **三角形** | 动感、锐利、危险、野心 | 玛琳菲森、刀疤 |

**阿甘的性格：乐观、倔强、底层但不阴暗，"知道生活很难但选择笑着扛"。**
→ **「倔强 + 扛得住」是方形，不是圆形。**

### 2.3 ⭐「主形稳定，副形捣乱」

> "一个软萌角色若全身都是圆，反而会失去情绪张力；
> 给他一对略向下压的眉峰，人物便有了小小的倔强。"

**阿甘必须是方形主形 + 圆形副形（乐观）**，而不是纯圆。

### 2.4 角色必须有「固有识别色」

> "固有识别色是观众远距离也能认出的核心。每个角色限制 3-5 种主导色。"

阿甘的识别色 = **黄袋鼠的亮黄**（他的职业色）。

## 三、四个形状方案实验（v4，8 张）

| 方案 | 形状赌注 | 结果 |
|---|---|---|
| **P1 方箱骡** | 躯干 = 方盒子（外卖箱长在身上） | ✅ **剪影最强**，但拟人化不足、头从箱子正面钻出 |
| P2 长脸天线 | 脸占全身 1/2 | ❌ 模型没理解，画成大耳狐 |
| P3 弹簧脖 | 脖子永远前倾 30° | ❌ 模型没理解，画成普通驴 |
| **P4 旧玩具** | 补丁、掉毛、一耳立一耳塌 | ✅ **拟人化最好** + 破损质感动人，但变成布偶熊、失去物种感 |

**结论：P1 贡献形状，P4 贡献拟人化与质感。**

## 四、三源合体（v5，4 张）

| 来源 | 取什么 |
|---|---|
| P1 | **方形躯干**（形状记忆点） |
| P4 | **两足站立 + 补丁磨损**（拟人化 + 底层劳动者的质感） |
| v3 | **骝色 / 倒伏鬃 / 长驴脸**（物种正确） |
| 新加 | **亮黄方箱 = 固有识别色** |

### ⭐ Q4 是目前最强候选

**构成**：黄色方箱躯干 + 棕色驴头从上方侧伸 + 细腿 + 一只手高举外卖袋 + 前倾赶路 + 箱体边缘有缝线和胶带磨损 + 左耳折下

### 实测数据

| 指标 | 数值 | 判断 |
|---|---|---|
| 剪影可辨识度 | 缩到 **48px** 仍可读出「方箱+驴头+举手+细腿」 | ✅ 达到 10 英里测试 |
| 宽高比 | 0.64 | ✅ 瘦 |
| **耳尖凹陷** | **2** | ✅ **23 张里第一次达成** |

**「左耳折角」比「左耳缺一角」可行。** v3 单独试折角失败（X2），
但在 Q4 里，因为整体有一个强形状支撑，模型把折角画出来了。

## 五、三个需要拍板的设计决策

### 决策 1：躯干要不要做成方箱？

**这是整个设计的赌注。** 

| 支持 | 风险 |
|---|---|
| 剪影独一无二，48px 可辨 | 可能"太怪"，偏离"治愈"调性 |
| 直接讲职业（外卖箱），不用说 | 观众第一眼可能看不懂"这是驴还是箱子" |
| 方形 = 倔强，符合性格 | 后续动作设计受限制（身体不能弯腰） |
| 爆笑虫子式的极简符号学 | 与"疯狂动物城"式的拟真拟人不同路 |

**备选**：保留方箱概念，但削弱成"方形肩膀/方形背篓"，不完全替代躯干。

### 决策 2：识别色用亮黄吗？

亮黄 = 黄袋鼠职业色 = 强识别，但**和美团黄撞色**（现实中外卖平台）。

**备选**：亮橙（橙蜜蜜是对手，不能用）/ 亮青 / 亮红。

### 决策 3：耳朵特征用「折角」替代「缺一角」

实测折角可行（Q4 达成），缺角 0/11 不可行。
