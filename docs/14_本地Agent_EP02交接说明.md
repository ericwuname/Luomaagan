## 4. EP02 的审查任务

请至少输出以下结果（先在回复/临时评审记录里给出；建议保存为 docs/15_EP02_剧本审查.md，但未经主创确认不要直接覆盖剧本）：

### A. 故事理解测试
- 不看创作说明，仅阅读镜头表，能否明白“不要按门铃—阿甘没按—鹦鹉模仿—兔子误会—证据澄清—整层楼被叫出来”？
- 是否有因果断点？特别是鹦鹉为什么看到阿甘后开始学门铃、兔子为什么认为阿甘按铃、其他住户为什么开门。
- 结尾“整层楼开门”是否自然、是否需要更强铺垫。如果不成立，请给一个更简单、更好拍的视觉反转。

### B. 喜剧与节奏审查
- 每个笑点有没有可见的设置、升级、反应和回收？
- 台词是否过于解释？能否先用动作讲清楚再补一句？
- “我就是个影子”“五星好评”等台词是否自然；是否有更快、更易笑的写法？
- 结尾是否真正达到“观众快速反应、能笑出来”，还是只是可爱/好懂？
- 不要加多个无关梗；保留一个核心喜剧机制。

### C. 制作可行性审查
- 逐镜标注：可复用现有素材 / 需要改造的现有素材 / 必须新生成。
- 查本地真实的素材文件路径、时长、内容；至少抽帧检查相关候选素材，不能只看文件名判断。
- 标出高风险镜头：角色一致性、室内外轴线、鹦鹉嘴部动作、门铃手部特写、结尾群体反应。
- 对复杂群戏优先提出低成本替代：同一走廊底片 + 3–4 个门缝反应，或连续快速切镜，不要一次要求模型生成大量动物。
- 核查 18 镜 / 108 秒的目标时长、台词实测长度和视频配额；按实际素材重算，不要靠过度变速补时长。

### D. 连续性与生成规范
- 阿甘全片使用 assets/hero/AGAN_MASTER_2k.png 或经核实的当前唯一主角参考；先确认本地文件实际状态。
- 所有中文 UI、五星星级与字幕使用程序/后期合成，不能让图像模型画字。
- 检查门轴方向、门铃位置、外卖袋落点、角色左右位置、室内外光线和鹦鹉栖木是否锁定。
- 空镜不要带主角参考图；有主角的镜头使用高分辨率参考。
