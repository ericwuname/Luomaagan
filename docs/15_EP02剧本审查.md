## 一、EP02 剧本建议：**小修后可进入首帧**

**核心判断：这个故事讲得通，笑点成立，而且是"能在画面里看懂"的那种。**

### 1.1 因果链逐环检查

| 环节 | 是否成立 | 说明 |
|---|---|---|
| 为什么不能按门铃 | ✅ 强 | 备注直接写出来，前 3 秒建立规则 |
| 阿甘为什么认真执行 | ✅ 强 | 他"想把每件事做对"的人物设定，且备注是客户要求 |
| 鹦鹉为什么学门铃 | ⚠️ **需补一环** | 见下方修改 1 |
| 兔子为什么误会 | ✅ 强 | 它戴耳机开会，鹦鹉学得太像真门铃 |
| 阿甘怎么澄清 | ✅ 强 | 手机静音 + 门铃始终没亮，双证据 |
| 整层楼为什么开门 | ⚠️ **反应方向要改** | 见下方修改 2 |
| "五星好评"从哪学的 | ❌ **缺铺垫** | 见下方修改 3 |

### 1.2 三处最小修改（都不增加镜头数）

#### 修改 1：06 镜末尾补一个"看门"的动作

**现状**：06 鹦鹉看到阿甘 → "咕？" → 08 突然学门铃。**中间缺一环，观众会问"它为什么突然学门铃"。**

**改法**：06 镜 prompt 末尾加一句——
> after watching him, **its head turns briefly toward the door and the doorbell beside it**, then back

**为什么有效**：观众自己会连起来——"它知道有人来 = 门铃会响"。**不增加镜头，不增加台词，只加一个转头动作。**

#### 修改 2：18 镜邻居的反应方向要改

**现状**：邻居"探头看着阿甘"。
**问题**：他们为什么看阿甘？讲不通。他们应该是**以为自己的外卖到了**。

**改法**：邻居开门的一瞬间——
> **their faces light up with expectation, eyes looking down at the floor outside their own doors**（expected a delivery bag），
> **then the expression drops into confusion as they see nothing there**

**为什么有效**：笑点从"可爱"变成"真的好笑"。**一扇门接一扇门亮起期待、又挨个垮掉**——这才是"整层楼被叫出来"的正确笑法。

#### 修改 3：02 镜给"五星好评"补一句来源

**现状**：16 镜鹦鹉说"麻烦点个五星好评"，但全片没人说过这句。剧本 F 节说"learned from previous riders"，观众看不到。

**改法**：02 镜阿甘说完"今天我就是个影子"后，**自言自语补半句**——
> 阿甘（很轻，像职业习惯）：「……记得五星好评。」

**为什么有效**：
1. 给 16 镜找到出处
2. **更好笑**——他自己念叨的职业习惯都被学了
3. 强化人物（一个跑单跑出肌肉记忆的人）

## 三、三个最高风险镜 + 应对

### 3.1 镜 05：蹄手悬停"一厘米"——**最高风险**

**风险**：模型极可能画成"已经按到"。这是全片的核心证据镜，一旦糊了，整个误会逻辑就塌了。

**三道防线**：
1. **prompt 反复强调空隙**：`a clearly visible gap of empty air between the hoof and the button` / `the hoof is NOT touching the button, there is space between them`
2. **用"悬停 + 影子"表达**：蹄手投在按钮旁的阴影，比"接触"更能说明"没碰到"
3. **保底方案**：如果 3 次生成都像"按了"，**改用静帧**——首帧（悬停）+ 末帧（收回）两帧做 0.3 秒微动，**完全不依赖视频模型**

### 3.2 镜 18：群戏——**必须降级处理**

**建议直接放弃"让模型画 4 只动物"**，改成本地可控的做法：

```
同一张走廊空镜（复用 D4）
  → 剪 3 个"某扇门开一条缝 + 一双眼睛 + 门内暖光"的短镜
  → 每个 1.2–1.5 秒，依次出现
  → 最后切回阿甘，他手里只有一份外卖
```

**这样"整层楼被叫出来"的笑点完全保留，但每镜只需要"一扇门+一双眼睛"，生成难度降低一个量级。**

### 3.3 镜 14/16：双人/三人同框——**轴线风险**

**风险**：兔子从室内开门，阿甘在门外，模型容易把两人放到同一侧，或者把门画到反方向。

**应对**：
- **在 prompt 里写死左右**：`Agan stays on frame LEFT, outside the doorway; the rabbit stays on frame RIGHT, inside`
- **加一句"门从室内向内开"**：`the door swings INWARD into the room`
- **16 镜（三人）如果崩了，拆成两镜**：兔子转头（单）→ 鹦鹉特写（单）。**不要死磕同框**

## 四、EP01 重构草案的意见：**方向应采纳，但暂缓开拍**

### 4.1 应采纳

**「我歪可以，蛋糕不能歪」是一个非常干净的视觉喜剧规则**，比现行《第一万单》强：

| 维度 | 现行《第一万单》 | 草案《我歪可以》 |
|---|---|---|
| 规则 | 无（靠情绪推动） | **一条看得懂的物理规则** |
| 升级 | 靠事件堆叠 | **靠坡度递增**，天然逐级 |
| 回收 | 靠陌生人善意 | **靠一句台词闭环 + 孩子发现生日旗** |
| 结尾按钮 | 无 | **下一单又是冰淇淋蛋糕，备注仍是"保持水平"** ← 这个收尾很专业 |

**结论：这个方向明显优于现行版本，建议作为 EP01 的下一版。**

### 4.2 需修改

1. **和 EP02 结构雷同**：两集都是「一条规则 → 逐级升级 → 回收 + 温暖落点」，都是 18 镜 107–108 秒。
   **建议：两集不要连着拍。先拍 EP02（用户已定），EP01 重构版隔一集再上，否则观众会觉得"又是一个套路"。**

2. **气泡水平仪是高风险道具**：小物件 + 需要看清刻度，AI 极容易糊成一块。
   **建议：改成更简单的视觉替身——比如他用「眼睛盯着蛋糕上的小旗」判断水平**（旗杆垂直=蛋糕水平）。这个不需要生成小道具，而且更可爱。

3. **"路面缓坡"很难生成**：AI 视频里"坡度"不明显，观众可能看不出他在补偿什么。
   **建议：改成"台阶/上坡/下车推行"三个明确的物理场景**，比"缓坡"更好拍。

### 4.3 不应采纳

**没有发现明显不该采纳的内容。** 草案本身是专业的。

## 五、协作流程（docs/13）的意见：**部分采纳**

**应采纳**：
- 分阶段验收（剧本 → 首帧 → 视频 → 声音 → 剪辑），不允许"剧本写完 = 成片完成"
- 每镜记录 prompt 原文、参考图、参数、耗时、失败原因
- 失败 3 次就换方法，不堆 prompt 死磕

**需修改**：
- 闸门设得太密会拖慢节奏。**建议简化为两道硬闸**：
  1. **剧本闸**：故事讲得通、笑点能被复述
  2. **首帧闸**：18 张首帧人工过一遍，角色/道具/轴线都对
  视频和剪辑阶段靠"出片再评"，不做逐镜审批。

**不应采纳**：
- 没有。
