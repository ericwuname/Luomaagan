# 矢量精修工作流（AI 做美术指导，我做精确修改）

> 确立：2026-10-22
> 用户定分工：**"你的美术指导就是 AI，然后你矢量精修"**

---

## 一、为什么走这条路

AI 文生图是**概率的**：说"耳朵短一点"，它会整张重画——脸变了、姿态变了、颜色也变了。
**改 10 次是 10 次掷骰子，不是 10 次迭代。**

所以分工：
- **AI 负责"好看"** —— 它擅长生成有美感的形体
- **我负责"可控"** —— 在矢量上精确改，改一个地方只有那个地方变

---

## 二、为什么卡通风特别适合矢量化

**卡通画本质就是矢量图**：平涂色块 + 黑描边 = 每个纯色区域都是一个封闭形状。

| 图类型 | 可矢量化 | 原因 |
|---|---|---|
| **卡通 / 平涂插画** | ✅ 极好 | 纯色块，边界清晰 |
| 照片 / 写实渲染 | ❌ 差 | 连续渐变，无边界 |
| 水彩 / 笔触画 | ⚠️ 一般 | 边缘模糊 |

**所以这条路只适用于本项目的美式卡通风格——正好是。**

## 三、完整流程

```
① AI 生成（美术指导）
       ↓  挑一张满意的
② vectorize2.py  位图 → 分层矢量
       ↓
③ refine_svg.py  精确修改（改色/隐藏/移动/缩放）
       ↓
④ 输出 SVG + PNG（可无限放大，永不跑形）
```

### ① AI 生成
`scripts/gen_agan_v*.py`，每张旁存 `*.prompt.txt`（提示词+参数+耗时，可回溯）

### ② 矢量化 `scripts/vectorize2.py`

**关键经验：矢量化的目的是「清晰的色块边界」，不是「完整还原」。**

| 参数 | 作用 | 推荐值 |
|---|---|---|
| `colors`（量化） | 先压到 22 色 | 22 |
| `filter_speckle` | 丢小噪点 | **40** |
| `layer_difference` | 相似色合并 | **96** |
| `color_precision` | 认几级颜色 | **3** |

**实测三档（以 T4 为例）：**

| speckle / layerdiff / precision | path 数 | 色组 | 文件 | 评价 |
|---|---|---|---|---|
| 24 / 64 / 3 | 22 | 20 | 47 KB | **✅ 质量与可编辑性平衡最好** |
| 40 / 96 / 3 | 14 | 14 | 37 KB | 主体完整，领带花纹丢掉 |
| 60 / 128 / 2 | 8 | 8 | 26 KB | 太简，只适合改大色块 |

**默认用 24/64/3（20 色组）。**

> ⛔ 踩过的坑：一开始用 `color_precision=6` + `layer_difference=16`，
> 结果 **812 个颜色组**——每个细微色差和网点都单独成层，根本没法编辑。
> **精度不是越高越好。**

### ③ 精修 `scripts/refine_svg.py`

```bash
# 看有哪些颜色组、各占多少
python refine_svg.py list in.svg

# 看每个大色块的编号/颜色/面积/包围盒（定位部件用）
python refine_svg.py report in.svg --min-area 2000

# 改色（按颜色）
python refine_svg.py recolor in.svg out.svg --like "#EED4A7" "#DEC6A0" --to "#F2C230"

# 改色（按区域，避免误伤）
python refine_svg.py recolor in.svg out.svg --like "#EED4A7" --box 280,380,560,620 --to "#F2C230"

# 隐藏某个部件
python refine_svg.py hide in.svg out.svg --like "#FFFFFF"

# 移动 / 缩放某个部件
python refine_svg.py move  in.svg out.svg --box 300,80,420,300 --dx -12 --dy 0
python refine_svg.py scale in.svg out.svg --box 300,80,420,300 --sx 1.15 --sy 0.9
```

**已实测**：把 T4 的背心（`#EED4A7` + `#DEC6A0`，2 个 path）改成黄袋鼠黄，
1 秒完成，其他所有部位分毫不差。

## 四、这套流程解决了什么问题

| 老问题 | 现在 |
|---|---|
| 角色漂移（每生成一次就变样） | **矢量是确定的，永不漂移** |
| "耳朵短一点"要重掷十次 | **改一个参数，1 秒** |
| 出三视图要碰运气 | **同一矢量，做三个副本分别转角度** |
| 改颜色要重新生成 | **改 fill，1 秒** |
| 剪影测试要抠图 | **矢量直接填黑，零误差** |

## 五、局限（如实说明）

1. **改"形状"仍然比改"颜色"难。** 现在能可靠做的是：改色、隐藏、整体移动/缩放。
   局部改形状（比如"耳朵再弯一点"）需要改 path 的控制点，工具还没做。
2. **矢量化会丢细节**：网点纹理、极细的毛发会被合并。若要保留，
   用 20 色组版本，或者后期用 SVG pattern 重新叠网点。
3. **AI 出形这一步仍是概率的**——可能要抽几张才有一张满意的。
   但这只发生在最前面一次，之后所有修改都是确定的。
