## 三、两个关键发现

### 3.1 ⭐ Agnes 文生图**不支持 negative_prompt**

交接书 6.1 给的提示词带 `Negative prompt`，直接调 API 报 400：

```
"negative_prompt 不是文生图队列支持的字段"
```

**这反而是好事**——《走蛟》的教训是"负面词对具体部位会反向召唤"，
现在模型强制走纯正向路线，我们只能写"它是什么"，不能写"它不是什么"。

**代价**：所有"必须避免"的特征（纯驴灰、白唇、直立鬃）只能用**正向描述覆盖**，
不能直接禁止。

### 3.2 ⭐ "立耳"和"不是纯驴"是一对矛盾

v2 把耳朵描述放最前面，**耳朵立起来了**（关键突破），但立刻**整体漂移成纯驴**：
长矛耳 + 直立鬃 + 灰毛 + 白唇——正好是交接书明令禁止的四条全中。

**根因**：模型的知识里只有
- 驴 = 长矛耳 + 直立鬃 + 灰毛
- 马 = 短耳 + 倒伏鬃 + 骝色

**它不理解"中间态"。** 一叫"立耳"就往驴跑。

**破解（v3 有效）**：骡子 = **马的体型 + 驴的脸**。
用马的语言讲身体、鬃毛、毛色，用驴的语言只讲脸。
- 耳朵：不写 `long tapered blade`（引导成矛）→ 改 `medium-length, rounded leaf shape`
- 鬃毛：写"短窄一条、**倒伏偏向一侧**"（最有效的反驴锚点）
- 毛色：不写 `dusty`（会变灰）→ 写 `reddish-chestnut, glossy sorrel`

**v3 结果：物种、毛色、鬃毛全对了。** 这条路走通了。

## 四、硬结论：**"耳尖缺一角"当前模型做不到**

11 张图，换过 4 种描述：

| 措辞 | 结果 |
|---|---|
| `LEFT ear tip has a chipped notch` | 没画 |
| `a small triangular piece missing` | 没画 |
| `a clean angular missing corner that dents the outline` | 没画 |
| `permanent fold near its tip, bent over like a boxer's ear`（折角替代） | 没画 |

**这不是措辞问题，是能力问题。** 模型在整体构图里不会去执行"局部缺一小块"这种精细指令，
它会把这句理解成"耳朵上有纹理"，然后在耳内画几条线。

**剪影测试的作用正在于此**：肉眼看图觉得"好像画了点什么"，
但一量"耳尖凹陷 = 0"，就是没实现。

## 五、方案建议（需要拍板）

### 方案 A：换一个**更容易在剪影里体现**的耳朵特征

| 候选 | 剪影可辨识 | 模型实现难度 | 与"干活一辈子"的契合 |
|---|---|---|---|
| **A1 一耳折角**（拳击手耳） | ★★★★ | 低 | ★★★★ 长期被轭具磨 |
| **A2 两耳一高一低**（不对称） | ★★★★★ | **极低** | ★★ 偏怪趣 |
| **A3 左耳比其他短一截** | ★★★★ | 低 | ★★★ 被磨掉一截 |
| A4 耳尖缺一小块（原设定） | ★★ | **高（实测 0/11）** | ★★★★★ |

**我推荐 A3「左耳短一截」**：
- 剪影里两根耳朵长度不同，一眼可辨
- 模型对"长度差异"的理解远好于"缺一个小块"
- 叙事上更狠：**不是缺一角，是耳朵被磨掉了一截**——比"蹭伤"更有分量
- 台词"那夜我爸犯了错"依然成立

### 方案 B：坚持原设定，改用**图生图 + 局部重绘**

先用 v3 的正确底图，再用 I2I 只重绘耳朵区域。
**风险**：《走蛟》实测 I2I 会让整体漂移，且这个 API 的 I2I 是否支持局部蒙版未验证。
成本更高，成功率不确定。

### 方案 C：放弃"耳朵"作为记忆点，改用别的

比如**脖子上一道旧轭痕**（剪影看不出来，但彩色图上明显）。
**代价**：失去"剪影可识别"这个硬指标的支撑。
