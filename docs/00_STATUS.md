## 四、声音

| 组件 | 做法 |
|---|---|
| **阿甘** | 云希 YunxiNeural（少年 18–27 岁），情绪靠**语速+音高**区分：兴奋 +22% / 失落 −18% / 自语 −20% |
| **鹦鹉** | 云夏 YunxiaNeural +62~66Hz 极高音高 + 加速 → 带通 320-3600Hz + 压缩 + 短回声 → 叠加程序合成的电子门铃 |
| **BGM** | `scripts/make_bgm.py` 纯 numpy 合成。钢琴 / 拨弦 / 木琴 + Schroeder 混响 |
| 门铃音效 | `work/ep02/audio/bell.mp3`（1318Hz 叮 + 1046Hz 咚） |
| 门轴吱呀 | `work/ep02/audio/hinge.mp3` |

**⛔ BGM 必须"会退"**：小声段和留白处要压到 0.22–0.26，
否则会把"静"垫高、削弱笑点冲击。
（实测：固定音量让 EP02 门铃落差从 24dB 掉到 13dB；加让路曲线后恢复 22dB。）

## 五、已验证的硬边界

| 项目 | 结论 |
|---|---|
| 中文出现在画面里 | ❌ 必乱码。手机 UI / 字幕全部程序渲染或后期烧录 |
| "蹄手停在按钮前一厘米" | ❌ 模型做不到，会直接画成"按下去"。**改用构图保证距离** |
| "门缝 + 一双眼睛" | ❌ 两次都失败。**改用声音（门轴响）替代** |
| 双人同框 | ⚠️ 容易冒出人类。必须明写 `all-animal world, no humans` |
| 群戏（4+ 角色） | ❌ 不做。降级成"单角色反应镜头"或"空镜 + 声音" |
| 角色参考小图 | ❌ 会丢特征 |
