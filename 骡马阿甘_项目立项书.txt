第 3 页
二、立项背景与创意来源
2.1 创意来源
项目的核心概念来自三个层次的叠加：
 现实地名：中国多地存在真实的“骡马市”（如西安骡马市步行街），自带烟火气与历
史感；
 网络谐音：“骡马”谐音“罗马”，呼应“条条大路通罗马”的底层奋斗叙事；同时谐音“牛
马”，与打工人自嘲文化共振；
 城市精神：借鉴“来了就是深圳人”的移民城市口号，改写为“来了骡马，就是骡马
人”，形成骡马城的身份认同内核。
2.2 对标作品
本项目的角色设计对标《爆笑虫子》（Larva）的极简表情与肢体喜剧，世界观氛围对标
《疯狂动物城》的拟人动物城市，叙事节奏对标短视频平台的日常搞笑短番。不同之处在
于：本项目把故事落在“中国城市打工人”这个最具体的现实土壤上。
2.3 市场判断
短视频平台上，“外卖骑手”“打工人日常”“治愈解压”三类内容长期稳定地拥有巨大流量。
本项目把这三类需求合并进一个原创 IP，用低成本 AI 工作流实现日更，具备规模化内容
供给能力。

第 5 页
四、主角设定
4.1 物种与生物学设定
阿甘是驴骡（hinny），即公马与母驴交配的后代，区别于常见的马骡（公驴 × 母马）。
这一设定构成阿甘的标志性台词与身世背景：
“那夜，我爸犯了错，然后有了我。”
驴骡的生物学特征（体型偏驴、比驴大一点、比马小）直接决定了阿甘的角色外形——瘦
小而非壮实，为后续与袋鼠、狗等其他骑手形成体型差埋下设计基础。
4.2 角色性格
乐观、倔强、底层但不阴暗。整体气质参考《海绵宝宝》的单纯与快乐，但不做幼稚化处
理。阿甘的快乐不是“没心没肺”，而是“知道生活很难，但选择笑着扛”。
4.3 标志性视觉特征（记忆点）
为使角色在缩略图与剪影状态下仍可被一眼识别，为阿甘锁定以下四个视觉锚点，后续所
有出图与出视频环节不得改动：
序号 记忆点 说明
1 左耳耳尖缺一角 幼时被磨坊轭具蹭伤。这是黑白剪影状态下最易识别
的锚点，也是“那夜我爸犯了错”的视觉落地
2 瘦小前倾的站姿 不站军姿，呈“永远在赶路”的微前倾；与袋鼠、狗等
骑手形成体型差
3 后脑一撮短鬃 脖子后沿仅留一小排短鬃毛，微微翘起；跑动时会晃
动
4 蹄爪化双手 前肢拟人但保留蹄甲，手指简化为三指；不穿鞋，脚
为分趾蹄
验收标准：将角色图涂成全黑剪影并缩小至头像尺寸，仍可一眼识别出“小骡子 + 缺耳尖”。通过
此标准方可进入下一环节。
不把尾巴列为主记忆点，避免特征过多互相抵消；尾巴作为辅助细节保留。
第 6 页
五、骡马城设定
骡马城是一座对标上海城市体量、深圳移民精神的中国城市，新旧交织，烟火气浓厚。全
城以“出卖劳动力”为核心生活方式，每个劳动者都靠一身力气吃饭。
城市三大圈层：
区域 定位 视觉特征
老城区 阿甘居住地 握手楼、窄巷、晾衣杆、沙县与拉面馆，暖橙
色调，烟火气
新城区 主要送餐区 写字楼、商场、门禁社区，冷蓝调，效率至
上、路难找
工业区 城市边缘 厂房、仓库、物流园，灰褐调，风大、路远、
狗多
城市核心场景（待后续补全气氛图）：
 骡马广场：外卖集散地，三家公司总部所在地；
 柳树巷 7 号：阿甘的出租屋，月租 300 橡果；
 松树街：富人区，小费多但门禁多；
 断桥 / 骡马河：阿甘每日必经之路；
 森林入口旧木板：刻有“来了骡马，就是骡马人”。
第 7 页
六、技术路线
本项目采用 Agnes AI 全模态免费 API 作为创作底座，覆盖文本、生图、生视频三个环
节，算力全部运行于 Agnes 云端，本地设备无 GPU 压力。
环节 推荐模型 用途
生图 agnes-image-2.1-flash 文生图、图生图、角色定妆、场景气氛
图、首尾帧参考
生视频 agnes-video-2.0 / 2.5 图生视频、首尾帧动画（异步任务，需
轮询）
文本 / 提示
词
agnes-2.0-flash 提示词翻译、剧本与分镜撰写、工作流
编排
接入方式：通过开源 Agnes Agent Skill（如 Yacey/agnes-ai-generation-skill）或 agnes-ai-cli
接入 Agent 工作流，让本地 Agent 自主调用接口、执行生成、本地归档。
重要约束：
 视频帧数需满足 8n+1 规则（如 3 秒对应 81 帧 @24fps），否则 API 会拒绝或静默改
片长；
 图生视频与多图视频依赖公网可访问的图片 URL，本地 localhost 部署时此类功能不可
用，需先将参考图上传至图床；
 中文提示词建议先翻译为英文再送入模型，可降低文字与语义层面的出错概率；
 所有包含中文的画面（制服 Logo、招牌文字、标语牌）一律后期用 PS 或后期工具打
标贴图，严禁依赖 AI 直接生成汉字。

八、风险与边界
 AI 出图的中文文字必然乱码，所有中文文字元素必须走后期制作；
 Agnes 视频接口存在限流（约 1 次/分钟），需在工作流中预留排队与重试机制；
 图生视频的质量对参考图一致性高度敏感，角色定型是后续所有环节的前提；
 角色一旦漂移到“纯驴”或“马身”形态，将直接破坏 IP 辨识度，需以剪影测试作为硬闸
门。
