## 核心方法论（docs/ 内详述）
1. 连续失败 3 次 = 方法错了，立即换维度（曾为一个声音修 7 轮）
2. 可辨识 != 好看（做出过 48px 可辨但丑的角色）
3. 形状语言：圆=温暖 / 方=固执 / 三角=危险。认出来靠形状，不靠细节
4. "美感杀手"六条：无动作线 / 平行曲线 / 负空间消失 / 镜像对称 /
   细节过载 / 色彩无层级
5. 记忆点是"配件"不是"改造身体"（海绵宝宝是方的，因为海绵本来就方）
6. 人格靠造型，不靠裸角色
7. AI 出形 + 矢量精修：AI 负责好看，矢量负责可控

## 工具链
- agnes.py           API 封装（密钥走 .env，不进仓库）
- vectorize2.py      位图 -> 分层矢量（实测参数 24/64/3 = 20 色组）
- refine_svg.py      矢量精修（改色/隐藏/移动/缩放，1 秒一版）
- silhouette_test.py 剪影测试（自动验收）
- agan_svg.py        参数化 SVG 生成器（实验性）
