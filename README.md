# 骡马阿甘 · Luoma Agan

> 原创 AI 短篇动画系列 · 每集 1–3 分钟 · 目标日更
> **一个底层外卖骑手骡子的快乐送货日常**

这个仓库是一个 **AI 全流程动画生产实验**。它不只放代码，更放**踩过的坑**——
因为在这个领域，「不要做什么」比「做什么」值钱得多。

## 一、故事一句话

**甘骡八（阿甘）**，一头瘦小的**驴骡**（hinny = 公马 × 母驴），在**骡马城**送外卖。

他的口头禅：

> **「那夜，我爸犯了错，然后有了我。」**

骡马城是一座对标上海体量、深圳移民精神的城市，标语是
**「来了骡马，就是骡马人」**。

**核心情绪：治愈、解压、笑着感动。明确拒绝负能量。**
阿甘的快乐不是「没心没肺」，是「知道生活很难，但选择笑着扛」。

## 四、⭐ 核心方法论（读完这一节就能少走一个月弯路）

### 4.1 连续失败 3 次 = 方法错了，立即停手换维度

前一个项目里，为一个声音修了 **7 轮**，每轮都更精细、都没解决。
前 6 轮都在**同一层的不同精细度**——那不叫迭代，叫重复。

**任何异常，先把链条上每一环单独量一遍，找到"哪一环开始不对"。
不要从最后一环往前猜。**

### 4.2 可辨识 ≠ 好看（这是本项目栽过的坑）

我们曾做出一个在 48px 剪影下仍可辨识的角色——**但它丑**。
**「能记住」和「好看」是两件事，都要，不能拿一个替代另一个。**

### 4.3 形状语言 = 情绪的速记符号

| 形状 | 情绪含义 | 代表 |
|---|---|---|
| **圆形** | 温暖、友好、安全、天真 | 米奇、阿宝 |
| **方形** | 扎实、可靠、**固执**、迟缓 | 超能先生 |
| **三角形** | 动感、锐利、危险 | 刀疤、玛琳菲森 |

**阿甘的性格是「倔强、扛得住」→ 应该是方形，不是圆形。**
我们前 11 张全用了圆形语言，所以「可爱但记不住」。

**「主形稳定，副形捣乱」**——全身都是圆会失去情绪张力。

### 4.4 「美感杀手」清单（逐条对照自查）

| 杀手 | 后果 |
|---|---|
| 没有**动作线**（Line of Action） | 像"脊柱上贴了块木板" |
| **平行曲线** | 手臂两条一样的弧 → 像香肠 |
| **负空间消失**（四肢贴着躯干） | 糊成一坨 |
| **镜像对称** | 像机器人、像护照照片 |
| 细节过载、到处碎线 | "毛躁又廉价" |
| 色彩无层级（到处高饱和） | 视觉噪音 |

**修正**：一条贯穿全身的 S 曲线动作线 / 手臂离开躯干留空隙 / 一条边直线一条边曲线 /
3/4 侧角 / 只留一处修补 / 一个主色 + 一两个强调色。

### 4.5 记忆点应该是「配件」，不是「改造身体」

回看经典角色，**没有一个"把职业道具变成身体"**：

- 海绵宝宝是方的 —— **因为海绵本来就是方的**
- 米老鼠三个圆 —— **因为老鼠本来就是圆的**
- 维尼的 Eeyore —— 靠**尾巴上的粉蝴蝶结**（一个配件）
- 爆笑虫子 —— 靠两只虫子的**粗细对比**

我们试过"把外卖箱做成身体"，剪影很强但丑。
**记忆点用配件承载：帽子 / 领带 / 耳朵上一圈黄胶带。**

### 4.6 人格靠「造型」，不靠「裸角色」

> 《疯狂动物城》："每一个动物都会有属于自己特定的**发型**，从发型中会传达很多信息——
> 性别、年龄和身份。" "**服装也是能够传达动物内心的活动变化**。"

我们前 3 轮死守"先定裸角色"，**裸角色没有戏剧性，磨十轮也不会有特点。**
**先做完整造型，再反推裸角色。**

### 4.7 ⭐ AI 是概率的，所以需要「AI 出形 + 矢量精修」

**AI 文生图的问题**：说"耳朵短一点"，它会整张重画——脸变了、姿态变了、颜色也变了。
**改 10 次是 10 次掷骰子，不是 10 次迭代。**

**分工**：
```
① AI 生成（美术指导）      ← 负责"好看"
② vectorize2.py 转分层矢量  ← 负责"可控"
③ refine_svg.py 精确修改   ← 改色/隐藏/移动/缩放，1 秒
④ 输出 SVG（无限放大，永不漂移）
```

**实测**：把角色背心从米色改成黄袋鼠色，只动 2 个 path，1 秒，其他分毫不差。

**关键参数**（实测三档，默认用第一档）：

| filter_speckle / layer_difference / color_precision | path 数 | 色组 | 评价 |
|---|---|---|---|
| **24 / 64 / 3** | 22 | 20 | ✅ 平衡最好 |
| 40 / 96 / 3 | 14 | 14 | 主体在，花纹丢 |
| 60 / 128 / 2 | 8 | 8 | 太简 |

> ⛔ 坑：用 `color_precision=6` 会出 **812 个颜色组**（每个细微色差单独成层），
> 根本无法编辑。**矢量化的目的是"清晰的色块边界"，不是"完整还原"。**

## 五、怎么跑

### 5.1 环境

```bash
python -m venv .venv
# Windows
.venv\Scripts\activate
pip install pillow numpy cairosvg vtracer pypdf
```

### 5.2 配置密钥（必做）

```bash
# 项目根目录建 .env，写一行：
AGNES_API_KEY=你的key
```

`.env` 已在 `.gitignore` 里，**不会进仓库**。
也可以直接用环境变量 `AGNES_API_KEY`。

> 需要 Agnes 账号（国内站 https://api.agnes-ai.cn/v1）。
> 图像模型 `agnes-image-2.5-flash`，视频 `agnes-video-2.5-flash`。

### 5.3 常用命令

```bash
# 生成一批候选
python scripts/gen_agan_v9_style.py

# 把某张图转成可编辑矢量
python scripts/vectorize2.py work/char/batch_xxx/AGAN_xx.png

# 看矢量里有哪些颜色组
python scripts/refine_svg.py list  xxx_v2_24_64.svg
python scripts/refine_svg.py report xxx_v2_24_64.svg --min-area 2000

# 改色（按颜色，或按区域）
python scripts/refine_svg.py recolor in.svg out.svg --like "#EED4A7" --to "#F2C230"
python scripts/refine_svg.py recolor in.svg out.svg --like "#EED4A7" --box 280,380,560,620 --to "#F2C230"

# 剪影测试（验收）
python scripts/silhouette_test.py work/char/batch_xxx/*.png
```

## 七、硬边界（不可违反）

1. **中文文字一律后期打标**，禁止让 AI 直接生成汉字（必然乱码）。
2. **提示词中显式锁定驴骡特征**，防止漂移到纯驴或马。
   有效做法：**用"马"讲身体和毛色，用"驴"只讲脸**。
   （模型只知道「驴=长矛耳+直立鬃+灰毛」，一叫"立耳"就往驴跑。）
3. **角色定型前不要进入成片生产**，避免批量返工。
4. **每一轮出图必须保留提示词原文与参数**（`*.prompt.txt`）。
5. **Agnes 文生图不支持 `negative_prompt`**，传了直接 400。只能写正向。
6. **密钥不写进代码**，只走 `.env` 或环境变量。
