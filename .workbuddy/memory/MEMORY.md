# 《骡马阿甘》项目 —— 长期记忆

> 立项：2026-10-22
> 定位：原创 AI 短篇动画系列，1–3 分钟/集，日更，治愈解压向

## 一、项目硬设定（源自立项书 + 交接书，不可擅改）

| 项 | 内容 |
|---|---|
| 主角 | 甘骡八（阿甘），雄性**驴骡（hinny = 公马 × 母驴）**，瘦小 |
| 口头禅 | "那夜，我爸犯了错，然后有了我。" |
| 城市 | 骡马城（上海体量 + 深圳移民精神），标语"来了骡马，就是骡马人" |
| 职业 | 黄袋鼠外卖平台骑手 |
| 风格 | **美式卡通复古**：粗抖黑描边 + 平涂 + 网点颗粒 + 暖褐色调 |
| 情绪 | 治愈、解压、笑着感动，**明确拒绝负能量** |
| 时长 | 1–3 分钟/集，无终局 |
| 四个记忆点 | ①左耳耳尖缺一角 ②瘦小前倾站姿 ③后脑一撮短鬃 ④蹄爪化双手（三指） |
| 标志动作 | 单手举外卖箱过头顶 + 另一手扶"隐形车把" |
| 验收铁律 | **涂黑剪影缩到头像尺寸，仍可一眼识别"小骡子+缺耳尖"** |

**工作流四步（禁止跳步）**：裸角色三视图 → 加动作锚点 → 套制服 → 表情表。
**角色定妆必须交发起人确认后才能进下一步。**

## 二、技术栈（已验证）

- Agnes API：`https://api.agnes-ai.cn/v1`，key 见 `scripts/agnes.py`
- 生图 `agnes-image-2.5-flash`：2K + 3:4，约 11–13 秒/张
- 生视频 `agnes-video-2.5-flash`：`mode` 只能 text/keyframe/reference
- 封装：`scripts/agnes.py`（含 `gen_image` / `gen_video` / `chat`）

### ⛔ 关键限制（实测）
1. **文生图队列不支持 `negative_prompt`** —— 直接 400。只能写正向。
   → 立项书/交接书里带负面词的提示词**原样不能跑**，必须改写成纯正向。
2. 所有中文文字必须后期打标，禁止 AI 生成汉字。
3. 图生视频需公网可访问的图片 URL。

## 三、定妆图进展（2026-10-22，3 批 11 张）

### ⭐ 突破：立耳可以做到
把耳朵描述**放 prompt 最前面**，写 `ears standing upright, stiff and erect, like antennas`。

### ⛔ 陷阱：一叫"立耳"就漂移成纯驴
v2 四张全部变成：长矛耳 + 直立鬃 + 灰毛 + 白唇 —— 交接书明令禁止的四条全中。

**根因**：模型只知道「驴=长矛耳+直立鬃+灰毛」「马=短耳+倒伏鬃+骝色」，**不理解中间态**。

**✅ 破解（v3 有效）：骡子 = 马的体型 + 驴的脸**
- 耳朵：不写 `long tapered blade`（引导成矛），改 `medium-length, rounded leaf shape`
- 鬃毛：写"短窄一条、**倒伏偏向一侧**"（最有效的反驴锚点）
- 毛色：不写 `dusty`（会变灰），写 `reddish-chestnut, glossy sorrel`
- 体型：`young workhorse, lean and wiry, long slim legs, flat belly`

### ⛔ 硬结论：**"耳尖缺一角"当前模型做不到（0/11）**
换过 4 种措辞（chipped notch / triangular piece missing / angular missing corner /
boxer's ear fold），**剪影检测"耳尖凹陷"全部为 0**。
不是措辞问题，是能力问题——模型不会在整体构图里执行"局部缺一小块"。

**已提交用户拍板方案**（见 `docs/01_定妆图诊断_v1.md`）：
- A1 一耳折角 / A2 两耳一高一低 / **A3 左耳短一截（推荐）** / A4 坚持原设定走 I2I

### ⚠️ 第二个做不到：**拟人化蹄手（0/11）**
写"三指蹄手"全部画成四足动物的蹄。需要单独强化或分步处理。
