## 续：用户点破"主角没有一眼记住的特征" → 形状语言重做

用户：「主角没有那种让人一眼就能记住的特征；你看看海绵宝宝、汤姆和杰瑞、
爆笑虫子这些角色能让人一眼就印象深刻……需要一定的什么，以及大胆突破的设计。」

### ⭐ 诊断（我之前 11 张全错在哪）
**全身都是圆形语言**：圆头、圆肚、圆眼、圆蹄。
**圆形 = 温暖友好天真 = 可爱。而"可爱"正是记不住的原因——所有萌系角色都可爱。**

### 查到的四条硬规律
1. **迪士尼「10 英里剪影」测试**：纯黑形状就能读懂
   米老鼠=三个圆的构成 / 海绵宝宝=方形躯体 / 爆笑虫子=红圆+黄细长，体型差 1:1.8
2. **形状语言**：圆=温暖天真 / **方=固执扎实** / 三角=危险锐利
   **阿甘性格"倔强、扛得住"→ 应该是方形，不是圆形**
3. **「主形稳定，副形捣乱」**：全身是圆会失去张力，要有一处冲突
4. **每个角色要有「固有识别色」**，限制 3-5 种主导色

### v4 四个形状方案（8 张）
| 方案 | 结果 |
|---|---|
| **P1 方箱骡**（躯干=方盒） | ✅ **剪影最强**，拟人化不足 |
| P2 长脸天线 | ❌ 模型没理解，画成大耳狐 |
| P3 弹簧脖 | ❌ 模型没理解，画成普通驴 |
| **P4 旧玩具**（补丁/一耳立一耳塌） | ✅ **拟人化最好**+破损质感动人，但变布偶熊 |

### v5 三源合体（4 张）
**P1 的方箱形状 + P4 的两足站立与补丁磨损 + v3 的骝色倒伏鬃 + 亮黄识别色**

**⭐ Q4 是最强候选**：黄色方箱躯干 + 棕色驴头从上方侧伸 + 细腿 + 一手高举外卖袋
+ 前倾赶路 + 箱体边缘缝线胶带磨损 + 左耳折下

### 实测（关键突破）
| 指标 | 数值 |
|---|---|
| 剪影 | **缩到 48px 仍可读出「方箱+驴头+举手+细腿」** |
| 宽高比 | 0.64 ✓ |
| **耳尖凹陷** | **2（23 张里第一次达成）** |

**⭐「左耳折角」比「左耳缺一角」可行**：
v3 单独试折角失败（X2），但在 Q4 里**因为有强形状支撑，模型把折角画出来了**。
→ 教训：**细节特征需要整体结构支撑才能被模型执行。**

### 需要用户拍板的三件事
1. **躯干要不要做成方箱**（整个设计的赌注：剪影独一无二 vs 可能太怪/偏离治愈调性）

## 续五：用户选定「B —— 你的美术指导就是 AI，然后你矢量精修」

### ✅ 工作流建成（`docs/04_矢量精修工作流.md`）

```
① AI 生成（美术指导）→ 挑一张
② vectorize2.py  位图 → 分层矢量
③ refine_svg.py  精确修改（改色/隐藏/移动/缩放）
④ 输出 SVG + PNG（无限放大，永不跑形）
```

### ⛔ 矢量化最大的坑：精度不是越高越好
v1 用 `color_precision=6` + `layer_difference=16` → **812 个颜色组**
（每个细微色差、每个网点都单独成层，根本无法编辑）

**v2 参数（实测三档）**
| speckle/layerdiff/prec | path | 色组 | 评价 |
|---|---|---|---|
| **24 / 64 / 3** | 22 | 20 | **✅ 平衡最好，用这个** |
| 40 / 96 / 3 | 14 | 14 | 主体完整，领带花纹丢 |
| 60 / 128 / 2 | 8 | 8 | 太简，只适合改大色块 |

**核心认知：矢量化的目的是「清晰的色块边界」，不是「完整还原」。**

### ✅ 精修器 `scripts/refine_svg.py`
支持：`list`（看色组）/ `report`（看包围盒定位部件）/
`recolor`（按颜色或按区域改色）/ `hide` / `move` / `scale`

**实测**：把 T4 的背心（#EED4A7 + #DEC6A0，2 个 path）改成黄袋鼠黄 #F2C230，
**1 秒完成，其他部位分毫不差。**

### 这条流程解决的老问题
| 老问题 | 现在 |
|---|---|
| 角色漂移 | **矢量确定，永不漂移** |
| 改一处要重掷十次 | **1 秒** |
| 三视图靠运气 | 同一矢量做三个副本 |
| 剪影测试要抠图 | 矢量直接填黑，零误差 |

### 局限（如实）
1. 改"形状"仍比改"颜色"难（局部改形需要动 path 控制点，工具没做）
2. 矢量化会丢细节（网点/细毛会被合并）
3. AI 出形那一步仍是概率的——但只在最前面发生一次

## 续六：用户「加入一些赛博朋克风，或者其他的你觉得合适的风格」

### 判断：赛博朋克与立项书有直接冲突
契合点：赛博朋克的核心是"高科技低生活"的底层劳动者，**外卖骑手是它最典型的职业**。
冲突点：立项书写「**暖褐色调 / 治愈解压 / 明确拒绝负能量**」，而赛博朋克是冷调霓虹+反乌托邦。
→ **所以出四个方向让效果说话。**

### 四个方向（`docs/05_风格探索.md`）
| 方案 | 赛博感 | 治愈感 | 记忆点 | 判断 |
|---|---|---|---|---|
| C1 纯赛博朋克（霓虹雨夜/全息招牌） | ★★★★★ | ★ | ★★★ | 太压抑，**只适合做"特殊集"** |
| **C2 暖赛博朋克**（暖褐底+黄青两色霓虹+全息价签） | ★★★★ | ★★★★ | ★★★★ | **⭐ 最佳折中，推荐** |
| C3 Solarpunk（太阳能/绿植/明亮） | ★★ | ★★★★★ | ★★★ | 太干净，**"底层"的重量没了，不建议** |
| **C4 复古未来主义 1970s**（橘子+奶油+橄榄绿/搪瓷配送箱） | ★★★ | ★★★★ | ★★★★★ | **⭐ 与立项书最同源，推荐** |

### ⭐ C4 的意外收获：**搪瓷硬壳配送箱**
比布袋子有记忆点得多，质感独特，复古未来感十足。**可能是目前最好的道具设计。**

### ⭐⭐ 这批图佐证了"漂移"问题
同一个 prompt 骨架，四张图出来四个不同的角色：
毛色（棕/灰/粉棕/灰）、体型（瘦/胖/胖/中）、手型（蹄/手套/蹄/蹄）、耳朵角度……
**→ 定风格后必须立刻矢量化锁死，之后所有改动都在矢量上做。**
这正是"AI 出形 + 矢量精修"分工的意义。
